USAGE:
List the fields you can target/set (no file needed):
  ras plan modify --grammar
List the fields and their current values in a specific plan:
  ras plan modify --grammar Plan.p01.hdf

  ras plan modify --dry-run Plan.p01.hdf "solvertype = GPU"
Set the compute core count:
  ras plan modify Plan.p01.hdf "corecount = 8"
Change several settings in one save:
  ras plan modify Plan.p01.hdf "solvertype = CPU" "corecount = 12" "usefbf =
